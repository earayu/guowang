# 评标专家评分表：结构、来源与标注

## 先接受一个事实：招标文件不附评分表

对 18 个标包全文以「评分表 / 打分表」精确扫描，**0 处命中**。招标文件给的是**评分细则**
（文字与表格条款），不是可填写的表单。所以"专家评分表"必须由我们自己按细则固化，
不存在"从文件里导出"这条路。任何声称导出了原表的说法都是编的。

## 六要素，能拿到的只有四个半

| 要素 | 来源 | 可得性 |
|---|---|---|
| 专家人数 | 投标人须知前附表 | ✅ 5 人及以上单数 |
| 分值权重构成 | 评标办法前附表之六 | ✅ 按分标，14 个分标各不同 |
| 商务评审细则 | 评标办法前附表之三 | ✅ 逐项可解析 |
| 报价评分算法 | 评标办法前附表之五 | ✅ 区间平均价浮动法 |
| **技术评分标准** | 技术规范书章节 | ❌ 本项目该章节为空 |
| **汇总规则** | 无明文 | ❌ 只能引通用做法 |

技术那一栏要特别当心：原件里第 445 段是章节标题、446 段是空段落、447 段已是下一个标题——
**该章节确实为空**，不是解析遗漏。技术规范书目录讲的是技术规范，不是评分标准；
招标包里 20 份附件也没有对应内容。这种"原件缺"的情形必须如实说缺，不能拿通用范本顶上还标成本项目原文。

## 商务 23 项 / 技术 16 项的实际结构

商务（前附表之三，84 行源表 → 4 组 23 项，分值合计 −8 ~ 100）：
业绩水平、资源实力、质量控制、投标响应、绩效评价、质量问题（**负分项**）。

技术（国网通用范本，6 组 16 项，27 ~ 100）：
业绩水平 4–10、资源实力 13–53、质量控制 6–12、投标响应 6–10、绩效评价 0–15、质量问题 −2–0。

两条解析陷阱：

1. **docx 合并单元格会在每行返回同一段文字**。按行计数会把 23 项数成 83 项。
   判断分组与新项的分界要按「内容是否变化」（`c0 != cur_group`、`c1 != prev_c1`），不能按行数。
2. **负分项存在**。合计公式不能只加不校验，要允许总额低于 0 区间并显式标注。

## 汇总规则：只能引通用做法，必须标注

招标文件正文没有写死汇总公式。公开渠道（ECP 通用做法）一致指向
**去掉一个最高分、一个最低分后取算术平均**；专家 5 人时即取中间 3 人平均。

这条必须标成 C 级来源（非本项目原文），并且公式要写成"样本不足时降级为算术平均"的兜底：

```
=IF(COUNT(区间)>2, ROUND((SUM(区间)-MAX(区间)-MIN(区间))/(COUNT(区间)-2), 2),
   ROUND(AVERAGE(区间), 2))
```

专家人数按 5 人做默认，但表里要留"人数可改"的说明——法规是"5 人及以上单数"，
写死 5 人在 7 人评标时会把公式算错。

## 来源分级必须写在表里，不能只写在文档里

本项目采用两级：

- **A 级**：本项目招标文件原文，可回读到章节 / 表行。
- **C 级**：国网通用范本或公开转述，须核对，**不是本项目原文**。

落地要求（缺一不可）：

1. 每个 sheet 的抬头写明本表来源等级。
2. C 级内容用不同的表头底色标出来，翻页也能看见。
3. 表尾加一行警示：`⚠ 本表依据国网通用技术评分标准范本整理，不是本项目招标文件原文`。
4. 另开一张「规则来源」sheet，逐条写：条目 → 来源等级 → 出处（文件 + 章节 / 表行 / 渠道）。

只在一处写"部分内容为通用范本"是不够的——表被单独截图、单独转发时，
那句免责声明就丢了，剩下的看起来就是本项目原文。

## 表单结构（已验证可用的形态）

一张工作簿，按专家拆页：

- `汇总（待确认规则）`：每位专家商务分 / 技术分引用 + 去极值后的最终值；标题写明规则待确认。
- `专家N-商务` / `专家N-技术`：逐项一行，列 = 组别 / 序号 / 评分项 / 分值区间 / 评分标准 / 得分 / 备注。
- `规则来源`：条目与来源等级对照表。

工程细节：

- 每项得分格加数据验证（`DataValidation`），把可选值限制在分值区间内，避免填出区间外的分。
- 合计用 `SUM(得分列)`，不要用逐项相加的长公式，加减项时不会漏改。
- 汇总页用引用（`='专家1-商务'!F35`），不要复制粘贴数值，否则专家改分后汇总不动。

## 边界

- 不代专家打分，不给任何投标人的得分预测或排名。
- 可以回答：评分标准的原文位置、分值区间、计算规则、汇总口径。
- 不可以回答：某投标人技术得分 / 商务得分 / 总分——库内没有专家实际打分。
- 表里的"待确认规则"标记不要为了好看去掉；规则未确认就是未确认。
