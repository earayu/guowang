前端静态禁区 · 检查清单

可静态扫描验收；通过后才能进入对客演示。对应 195 号文第（十一）条「模型结论不替代自主判断、不改变法定责任」。

O5 · 合规
  • 页面不存在「一键通过 / 自动否决 / 赋分 / 定标」控件或等价接口调用
  • 不存在 fetch('/api/v2…') / XHR / 平台 SDK 直连（唯一取数 = fe-evidence-bridge → apemind CLI）
  • 不存在自动拼 --confirm 的代码路径；确认必须来自人工动作
  • 凭据字段（token / api_key / Authorization / Cookie）不出现在页面状态、localStorage、日志与 URL
  • 每条 AI 输出默认带「候选·需人工判定」，无「已判定」态
  • 退出码 4 / confirmation_required 在 P5 显式可见，不被前端吞掉
  • 库外题显示独立「证据不足」卡，不用空白或术语凑答
  • 白名单由 capabilities --json 生成；CLI 版本漂移时阻断发问
  • 引用回读带「批次 + 标包 + 固化 ID」三段式归属
  • 图谱未全绿、解析失败、限流、部分失败均有独立状态，不写成全绿
不得表述为：「DSH 已生产就绪」「插件可改平台权限」「前端可自动判定」「已满足国网要求」「可上线」「准确率 XX%」。本线框是 L1 demo 档，L2/L3 不在范围内。
